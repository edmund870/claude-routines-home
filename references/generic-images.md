## Selection rules

1. Determine post sentiment: bullish / bearish / neutral
2. Determine post topic: crypto / options / macro / charts / fintech
3. Pick from the matching category. One image per post.
4. **Never use BULLISH images for bearish posts.**
5. For bearish posts: always pick from CHARTS (no directional visual).
6. Topic beats sentiment: a bearish crypto post gets CRYPTO image, not CHARTS.
7. Rotate — do not reuse the same image in back-to-back posts this run.
